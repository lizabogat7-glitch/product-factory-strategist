# Стратег Фабрики продуктов

MGIMO

[Стратегия](demo/strategy.md) · [Описание проекта](docs/Описание.pdf) · [Видеообзор](docs/Обзор.mp4)

Откройте эту папку в Cursor или Codex с доступом к чтению и записи файлов. Для расчётов и контрольных точек нужен Python 3.8+. Дополнительных пакетов и ключей нет. Модель предоставляет выбранная среда по вашему тарифу. Для исследования сайтов нужен разрешённый браузер или поиск в этой среде. Готовый кейс можно проверить офлайн.

**Новый проект.** В чате напишите «Прочитай AGENTS.md. Начни проект router. Решение для руководителя — стоит ли менять обслуживание вторых SIM? Материалы приложу». Агент создаст отдельную папку и определит первый вопрос.

**Продолжение.** В новом чате напишите «Прочитай AGENTS.md и продолжи demo. Что нужно решить сейчас?» Чтобы прерваться, напишите «Сохрани точку остановки». Для исправления укажите источник и изменившееся значение.

**Проверить демо** из корня папки:

    python3 tools/case.py status demo
    python3 demo/forecast.py

Откройте demo/strategy.md для решения и demo/materials для проверки оснований. Данные учебные. Капитан публикует архив и видео в выбранном хранилище и проверяет доступ для жюри.
